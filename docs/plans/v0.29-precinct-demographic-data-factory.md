# v0.29: Precinct demographic data factory

Date: 2026-08-28

## Product objective

Turn the state-specific demographic foundations proven in v0.28 into a reproducible admission path for election-cycle local terrain.

The target chain is:

```text
checksum-verified Census block composition
                    +
checksum-verified election-unit geometry
                    ↓
county-bounded deterministic allocation
                    ↓
compact precinct demographic artifact
                    +
complete build-time block trace
                    ↓
audited Sandbox demographic capability
```

This phase improves aggregate geographic evidence. It does not create individual voter identities or observed candidate preference.

## v0.29A: Universal artifact and trace contract

Status: implemented

- Define a national-ready compact precinct artifact independent of PA, MI, or WI exceptions.
- Define a build-time trace with one canonical record per Census block.
- Reconcile all five aggregate VAP groups from source blocks through allocation targets and map units.
- Preserve unavailable blocks and unavailable map units explicitly.
- Require strict county-boundary containment for every allocation.
- Separate direct assignment, deterministic population split, and unavailable evidence.
- Preserve split evidence as exact rational weights whose numerators sum to one shared denominator.
- Exclude raw polygon-area allocation from the admitted method vocabulary.
- Bind demographic, geometry, and election-result source checksums.
- Add canonical serialization, SHA-256 fingerprints, unknown-field rejection, and input-order independence.
- Authorize no application migration or new state behavior.

## v0.29B: Reference spatial compiler

Status: implemented

- Added a headless compiler for normalized Census-block and election-unit Polygon or MultiPolygon geometry.
- Assigned whole blocks through containment or an in-block Census internal point.
- Resolved genuine multi-unit blocks only through positive population or housing evidence.
- Reduced equivalent split ratios canonically and allocated all five groups with exact integer conservation.
- Preserved invalid, unmatched, county-conflicting, and zero-information source blocks as unavailable evidence.
- Failed closed on invalid map geometry, overlaps, duplicate identity, unsupported CRS, unknown split bases, fractional weights, and out-of-block evidence points.
- Emitted the compact artifact and complete trace through the v0.29A contract.
- Added a reproducible bounded synthetic fixture, checked compiler artifact, source command, fingerprints, and adversarial verification.
- Migrated no current state foundation.

- Retained the admitted runtime: no strictly better replacement evidence. Full comparison, source hashes, block trace, size audit, and reproducibility are recorded in decision 0058. This is not statewide validation.

## v0.29D: Michigan comparison proof
