# v0.27C: Comparison and polish

Date: 2026-08-24

## Outcome

v0.27C completes the Swingometer explanation phase. Contributors now has two views inside the existing dock:

- **Movement** ranks the exact certified-to-scenario vote changes already carried by the scenario delta ledger.
- **Result structure** compares the geographic foundations of the certified and modeled pluralities side by side.

Each result-structure column uses that endpoint's true plurality winner and true statewide runner-up. When a scenario changes Pennsylvania from Trump to Stein, the certified column explains Trump's advantage over Harris and the scenario column explains Stein's advantage over the actual modeled runner-up. The interface never forces that change into a Harris-versus-Trump proxy.

## Interaction changes

- County and reporting-unit structure rows open the existing data inspector.
- Up, Down, Home, and End move keyboard focus through ranked geography lists.
- The Inspector tab receives focus after a contribution selection and offers a direct return to Contributors.
- The inspector now states certified and scenario plurality before showing the explicitly labeled H-T movement diagnostic.
- Certified and scenario columns collapse to one column on narrow screens.
- The mobile map legend uses tighter spacing and shorter visual ramps without removing candidate meaning.

## Model law

The comparison is deterministic and headless. For each endpoint it:

1. identifies the five-candidate plurality winner and statewide runner-up;
2. computes each geography's signed winner-minus-runner-up contribution;
3. ranks positive anchors canonically;
4. retains the strongest opposing geography;
5. reconciles all geographic contribution rows to the exact statewide plurality margin.

A tied endpoint has no invented winner hierarchy. Aggregate Other/write-in remains an aggregate bucket, not one named candidate.

## Boundary

No second chart renderer, dashboard wall, probability model, projection, Decision Desk logic, demographic behavior, or backend was added.

Demographic work begins separately in v0.28A with an evidence contract.
