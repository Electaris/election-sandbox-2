# v0.28C: Candidate-complete group preference

Date: 2026-08-26

## Outcome

Pennsylvania and Michigan users can now decide how newly added ballots for an authored demographic turnout assumption divide among Harris, Trump, Stein, Oliver, and residual Other/write-in.

## What changed

- Added optional five-candidate vectors for all five admitted aggregate demographic groups.
- Restricted each vector to ballots created by that group's turnout setting.
- Preserved the shared Harris-Trump added-ballot split as the explicit inherited default.
- Added exact deterministic integer allocation at group and reporting-unit level.
- Expanded statewide turnout, candidate, county, portfolio, contribution, and Election Night endpoints to remain candidate-complete.
- Added scenario URL schema 4 with schema 2 and 3 compatibility.
- Added linked five-candidate controls that always rebalance to exactly 100 percent.
- Kept Wisconsin fail-closed because its runtime has no compatible group-composition cells.

## Interpretation boundary

This is authored candidate choice for new counterfactual ballots. It is not an estimate of how a demographic group voted, and certified ballots are never assigned a demographic identity.
