# v0.29A: Precinct demographic artifact contract

Date: 2026-08-28

## Outcome

Sandbox now has a state-independent contract for producing auditable aggregate demographics on election-unit terrain.

## What changed

- Added a compact precinct, ward, or VTD demographic artifact.
- Added a full build-time Census-block allocation trace.
- Added exact five-group VAP reconciliation at block, target, map-unit, method, coverage, and statewide levels.
- Added strict county-boundary protection.
- Added explicit direct, population-split, housing-split, and unavailable semantics.
- Preserved exact rational evidence weights for every split target without floating-point arithmetic.
- Rejected raw area weighting as an admitted population method.
- Added source identities, vintages, and SHA-256 checksums.
- Added deterministic normalization, canonical serialization, fingerprints, and fail-closed deserialization.
- Added explicit unavailable map units and off-map election-unit counts.

## Product effect

No current Pennsylvania, Michigan, or Wisconsin runtime changes. No slider or map behavior changes. This is the admission constitution for the spatial compiler and future state foundations.
