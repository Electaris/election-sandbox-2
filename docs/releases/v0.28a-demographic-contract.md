# v0.28A: Demographic evidence and model contract

Date: 2026-08-24

## Outcome

The demographic phase now has a trustworthy foundation before any new slider is allowed to change votes.

The admitted PA, MI, and WI foundations compile into one deterministic inventory that records denominator meaning, population vintage, map geography, crosswalk method, local coverage, off-map units, composition availability, and future behavior eligibility.

## Important findings

- Pennsylvania has direct five-category 2020 VAP composition on Census VTD geography.
- Michigan has five-category 2020 VAP composition through a mixed bridge to 2024 precincts. Its 218 registered-voter-weighted split polygons remain labeled as deterministic allocations, and 72 unavailable bridges remain unavailable.
- Wisconsin has an admitted total VAP denominator but no group-composition cells in the current runtime artifact. It remains valid for aggregate turnout behavior and unavailable for group-specific behavior.

## Model law

The contract makes the following distinctions enforceable:

- VAP is not CVAP.
- 2020 population is not a 2024 eligible-voter estimate.
- aggregate group composition is not individual turnout;
- aggregate group composition is not candidate preference;
- future group turnout and preference settings must be user-authored assumptions;
- ecological inference is not allowed;
- v0.28A cannot mutate votes.

## Boundary

This release adds no UI control and changes no scenario result. v0.28B is the first phase authorized to implement group-specific turnout behavior for states whose evidence contract supports it.
