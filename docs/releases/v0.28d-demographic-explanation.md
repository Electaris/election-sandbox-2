# v0.28D: Demographic contribution and sensitivity

Date: 2026-08-26

## Outcome

The Turnout editor now explains exactly what each selected demographic assumption added and where the modeled change entered the result.

## What changed

- Added requested, realized, and capacity-clipped ballot readouts.
- Added an exact Harris, Trump, Stein, Oliver, and residual Other/write-in contribution ledger.
- Added signed Harris-minus-Trump movement for the selected operation.
- Added county and local reporting-unit contribution rankings.
- Added mapped-unit and off-map disclosure.
- Added deterministic margin movement per 1,000 added ballots as a bounded sensitivity readout.
- Added explicit operation-order language so later preference and third-party exchanges are not confused with turnout insertion.

## Interpretation boundary

The rankings explain model arithmetic, not individual causation. The sensitivity is not a forecast or probability and does not claim that the same group would vote this way in a real election.
