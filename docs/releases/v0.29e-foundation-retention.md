# v0.29E: Foundation retention checks and integrated verification

Package version: 0.29.7. Completed: 2026-09-12.

The three-state retention decision now has a repeatable build gate. Both production build commands verify the reviewed demographic artifacts, source/configuration inventory, geometry manifests, and all 222 county map files before compiling. Unreviewed data changes, incompatible state routing, or changed demographic capabilities fail the check.

The gate uses the application's actual runtime adapters and model. It preserves every zero-change model unit, reconciles detailed totals with the national baseline, accounts for off-map votes separately, and verifies that PA/MI support group assumptions while Wisconsin rejects them.

The integrated browser review also found a stale assertion expecting scenario URL version 2. It now expects the existing version 4 serializer. Election Night screenshots can be directed to the current review directory without replacing earlier review images on subsequent runs.

Pennsylvania, Michigan, and Wisconsin retain their current foundations. This release does not admit a candidate, change runtime data, resolve Michigan's source hold, complete human testing, or authorize public delivery. Replacement admission requires a new reviewed policy and tested runtime integration.
