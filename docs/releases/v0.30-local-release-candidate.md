# v0.30: Local three-state release candidate

Version: `0.30.0-rc.1`. Date: 2026-10-11.

The retained PA/MI/WI product can now be packaged as an identifiable local release candidate. `npm run release:package` builds through the existing foundation gate and creates a directory containing compiled assets, review documents, and a complete checksum manifest. `npm run release:verify` rejects changed, missing, or extra assets and changed workspace build inputs. Existing candidate directories are never overwritten.

The manifest records dirty-tree provenance honestly; no commit or historical tag is created or moved. Public/paid delivery and completed human acceptance remain false. The next step is the ten-task owner walkthrough against the exact content ID.
