# v0.29D.1: Michigan source normalization audit

Date: 2026-09-08

Version: 0.29.4

Michigan's original candidate lost evidence to invalid and overlapping source polygons. A versioned native-coordinate normalization now resolves 20 invalid ring representations and six tolerance-bounded overlap strips, while a documented Flint effective-cycle interpretation preserves the raw source year.

The full statewide rerun raises complete precincts from 3,645 to 3,956 and reduces unallocated VAP from 176,577 to 5,071. One source overlap remains between City of Sturgis Precinct 2 and Sturgis Township Precinct 1, leaving both targets quarantined. Another 382 precincts are partial. Fourteen formerly complete diagnostic precincts become partial under the changed geometry representation; the report includes these regressions.

**Retain the existing runtime.** Candidate admission remains rejected. All 74 off-map units / 142,574 votes and the admitted Michigan files remain unchanged. No frontend behavior or application demographics are migrated.

The release adds source hashes, a full per-target normalization audit, all-block trace, comparison against both v0.29D and the admitted VTD foundation, and adversarial normalization tests.
