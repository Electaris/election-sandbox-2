# v0.27B.1: Five-candidate dock semantics

Date: 2026-08-23

v0.27B.1 is a correctness patch for scenarios in which Stein, Oliver, or aggregate Other leads. It does not change any scenario endpoint or chronology. It makes every primary result surface use the same five-candidate plurality law already used by the map.

## Swingometer

- Contributors leads with the actual-to-scenario plurality transition.
- A third-party flip ranks the operation, county, and reporting-unit evidence by the winning candidate's vote change instead of an incidental Harris-Trump rounding difference.
- The decisive delta, causal chain, waterfall, and contributor rows name the candidate they measure.
- Harris-Trump contribution analysis remains available when that is the decisive result metric.
- Inspector and Behavior retain operation-specific H-T diagnostics only where they are explicitly labeled.
- The Electoral College target selector includes Harris, Trump, Stein, Oliver, and aggregate Other.
- The scoreboard assigns EV to each named winner instead of collapsing every non-major candidate into one undifferentiated bucket.
- Threshold, state-flip, consequence-ledger, and Path to 270 calculations all follow the selected candidate against their strongest opponent.
- National popular-vote readouts show all five modeled candidate buckets. H-T margin remains only where it is explicitly identified as an H-T diagnostic.
- Unsupported states retain unseparated minor-candidate ballots in aggregate Other. The interface states this limitation instead of inventing named candidate totals.
- Shared scenario URLs preserve every supported target candidate.

## Election Night

- The primary timeline is now a five-candidate reported-share chart.
- State and visible-prefix readouts show the leader over the runner-up, including Stein, Oliver, and aggregate Other.
- The local return tape receives all five candidate buckets and leads with the return's true plurality.
- Live movement windows, mover rankings, and return-tape secondary text retain the signed Harris-minus-Trump analytic under explicit `H-T` labels.
- Window rows show the plurality of ballots published in that window before the H-T diagnostic.
- State path text compares the current plurality leader with the runner-up rather than treating the count as only Harris versus Trump.
- The Election Night legend now includes the third-party ramps.

## Invariants

- No vote total, local allocation, endpoint, event time, or event identity changes.
- The timeline is still current-prefix only. Hidden future candidate shares cannot enter a displayed point.
- Reporting velocity and progress remain candidate-neutral.
- Shift remains an explicitly Harris-versus-Trump analytic.
