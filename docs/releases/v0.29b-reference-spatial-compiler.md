# v0.29B: Reference spatial compiler

Date: 2026-08-29

## Outcome

Sandbox now has a deterministic headless reference compiler that turns Census-block composition and election-unit geometry into the audited v0.29A demographic bundle.

## What changed

- Added normalized Polygon and MultiPolygon geometry admission in `OGC:CRS84`.
- Added whole-block containment and Census internal-point assignment.
- Added population and housing evidence splits with reduced exact rational weights.
- Added exact integer allocation for all five VAP groups with canonical remainder ordering.
- Added strict no-cross-county allocation and fail-closed overlap handling.
- Added explicit unavailable outcomes for missing geometry, invalid source geometry, county conflicts, and zero-information splits.
- Required every internal point and split evidence point to lie inside its source block.
- Rejected unknown split bases and retained the prohibition on raw area weighting.
- Added a reproducible synthetic source fixture and a checked canonical compiler product.
- Added a CLI compiler command: `npm run data:v029b:reference`.
