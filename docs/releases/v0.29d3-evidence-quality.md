# v0.29D.3: Evidence quality and foundation retention

Package version: 0.29.6. Date: 2026-09-08.

Michigan's diagnostic completeness labels did not expose positive blocks that touch only foreign-county precincts. The new deterministic review separates touching evidence from source-county localization, preserves the frozen statuses, and documents retention of all three existing state foundations for bounded v1.

- Enumerates 179 unique positive-VAP unavailable blocks, including 26 / 491 VAP outside Sturgis quarantine, with all six demographic cells and affected target identities.
- Reviews all 382 partial precincts and 14 regressions. Two unlocalized positive blocks require county context for 63 Bay/Isabella precincts, including 52 labeled diagnostic complete.
- Reconstructs all eight Flint Township candidate profiles by source VTD and block. Precinct 2's 5,759 VAP comprises three VTD contributions; its existing bridge uses one. Arithmetic provenance does not independently validate the boundary.
- Pins the existing PA/MI/WI runtime demographic artifacts and records retention decisions. No candidate is admitted, no population is reassigned, and no zero-VAP partial is promoted.
